Recommended direction strategy

FIRST_LAST is the safest gate policy when the terminal only records punches. It treats the earliest accepted punch as arrival and the latest as departure. Use DEVICE only where the hardware reliably sends IN/OUT. Use ALTERNATE for simple clocks where punches intentionally alternate.

Parent departure alerts need reliable direction

Arrival can be inferred from the first accepted punch. Departure alerts are only sent for an explicit OUT/BREAK_OUT event so an ordinary repeated scan cannot falsely tell a parent that a learner left school.
